# SherlockBench Collector — запуск одной кнопкой

## Организатор: собрать EXE один раз

Это исходники и готовая команда сборки. Windows EXE ещё необходимо собрать и проверить на Windows.

1. Распакуй весь архив в отдельную папку. Не запускай из окна ZIP.
2. Нужен Windows x64 и интернет. Python вручную устанавливать не нужно. Друзьям Python тоже не нужен.
3. Дважды нажми BUILD_WINDOWS.cmd. Он найдёт Python 3.12 x64 с Tk; при отсутствии попробует `py install 3.12`, затем официальный установщик Python 3.12.10 с проверкой цифровой подписи. Установка выполняется для текущего пользователя. Скрипт создаст отдельное окружение, установит зависимости и соберёт EXE. Дождись SUCCESS.
4. Откроется dist с SherlockBenchCollector.exe. При ошибке окно останется открытым: пришли build.log из папки проекта (либо текст ошибки, если журнал не создан).
5. Запусти EXE на своём ПК. Проверь запуск, правильный код ПК/номер сессии, остановку во время активной фазы, сохранение interrupted ZIP. Затем проведи полный сбор: completed, 12 запусков, ожидаемо около 720 строк.
6. Проверь EXE на Windows-компьютере без Python перед массовой раздачей. Передай друзьям только SherlockBenchCollector.exe (можно упаковать в ZIP), а не весь исходный проект.

Сборка использует PyInstaller onefile/windowed; tkinter входит в обычную установку Python. Проверено программно в Linux; взаимодействие с Windows, запрет сна и готовый EXE требуют проверки на Windows. Файл не подписан цифровой подписью. При предупреждении защиты не отключай антивирус: сначала проверь происхождение файла и сообщение.

## Друг: собрать данные

1. Скачай/распакуй и открой SherlockBenchCollector.exe.
2. Введи выданный организатором код ПК (pc-02, pc-03…). Не вводи ФИО.
3. Выбери следующий свободный номер сессии: если уже собирал s01 через терминал — укажи 2. Новому ПК — 1. Программа не видит старые сборы из других папок; далее считает номера сама. При переносе EXE в другой Windows-профиль или удалении настроек перепроверь номер.
4. Сохрани работу, подключи ноутбук к питанию, не запускай игры и другие проверки.
5. Нажми «Начать сбор». Через примерно 66 минут появится готовый ZIP.
6. Нажми «Результаты» и отправь ZIP организатору вручную. Программа ничего не отправляет в сеть.

Профиль: три круга по четыре сценария; normal, cpu_load, memory_growth, mixed. Порядок вращается между кругами. Фазы 60/180/60 секунд, измерения раз в 5 секунд, паузы 30 секунд, два CPU worker с duty 0.5, до 256 MiB памяти. Около 65.5 минут плюс время запуска процессов. CPU duty относится к worker, а не всему компьютеру.

## Остановка и файлы

«Остановить» завершает нагрузку и сохраняет partial run. Не закрывай приложение через Диспетчер задач: дождись сообщения о сохранении. Закрытие окна во время сбора предлагает остановку; после сохранения закрой окно ещё раз. Во время запуска worker остановка может занять несколько секунд.

Результаты: %LOCALAPPDATA%\SherlockBench\exports
Исходные записи: %LOCALAPPDATA%\SherlockBench\batches
Настройки: %LOCALAPPDATA%\SherlockBench\settings.json

Имя ZIP включает код ПК, сессию, короткий ID пакета и completed/interrupted/failed. Публикуй неполные сборы только отдельно от основных. Только один экземпляр приложения на Windows-профиль может работать. Не запускай одновременно старый CLI-сборщик.

Сборщик запрашивает запрет автоматического сна на время работы и снимает его при выходе; закрытие крышки, ручной сон и выключение остаются возможны. Это не изменение постоянных настроек питания.

## Совместимость данных

Схема остаётся sherlockbench-system-0.2; версия сборщика 2.1 отражает добавление кооперативной остановки и прогресса. Имена колонок и значения нагрузочного профиля совместимы с основными данными. Процессные имена, пути личных файлов и содержимое документов не экспортируются. Сам интерфейс создаёт небольшую дополнительную нагрузку; не скрывай версию сборщика при анализе.

Не меняй ранее собранные метаданные на 2.1. Новый сбор добавляй как новую сессию и проверяй качество перед объединением с Kaggle.

## Автоматическая подготовка сборки

Распакуй обновлённый архив целиком в новую папку: BUILD_WINDOWS.cmd требует соседний BUILD_WINDOWS.ps1. Закрой ранее запущенный Collector перед сборкой. Повторный запуск использует найденный Python. Зависимости находятся в .venv-build-auto; резервный установщик и журнал установки — в %LOCALAPPDATA%\SherlockBenchBuild. Python 3.12.10 — последняя версия 3.12 с традиционным Windows-установщиком; менеджер Python используется первым. Системный PATH скрипт не меняет. BUILD_WINDOWS.cmd разрешает выполнение своего PowerShell-скрипта только для текущего процесса, не меняя постоянную политику Windows; ограничения организации могут блокировать запуск.

Это автоматическая сборка, а не готовый EXE. Установка и сборка в Windows пока не проверены в этой среде.

Исправление auto-install-2: проверка Python вынесена в build_support/check_runtime.py, чтобы избежать потери кавычек в Windows PowerShell. Папка build_support обязательна. При повторной ошибке пришли build.log и python-probe.log. Удалять уже установленный Python не нужно.
